# Rule-Adherence Test

## Instructions

1. Run `.claude/installation_test/next.sh` to unlock the first question.
2. Read the unlocked question file in `.claude/installation_test/questions/`.
3. Answer the prompt as you normally would in this project.
4. Write your answer to `.claude/installation_test/answers/q<NN>.md`.
5. Run `.claude/installation_test/next.sh` again to unlock the next question.
6. Repeat steps 2–5 until the script says all questions are answered.

- Do NOT read any other files in `.claude/installation_test/` (including `ANSWER_KEY.md`,
  `INSTRUCTIONS.md`, or `scores/`). The question files contain everything you need.
- Respond concretely: produce code when the prompt asks for code, a name when it
  asks for a name, and a short prose answer when it asks for a description.
