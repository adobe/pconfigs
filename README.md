# pconfigs

**A python library for reproducible research and flexible system design.**

**Research & deep learning code should**
1. *Be Reproducible.* The same command should produce the same result as it did 2 years ago.
1. *Be Extensible.* It should never be impossible to modify/repurpose the code for new problems.
1. *Be Transparent.* One should be able to read the code alongside all configured parameter settings.
1. *Be Maintainable.* One should be able to maintain the code as the repository around it evolves.

## Installation
```
pip install pconfigs
```
